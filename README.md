## 🌟 What's New in v1.1.0

- 📑 **Multi-Document Studio Tabs**: Work on up to 5 notebooks simultaneously with sub-second tab switching, exact active page memory, live page badges, and LRU auto-eviction.
- 📋 **External Image Clipboard Paste**: Paste images directly from the Windows clipboard into notes. Full support for **Windows Snipping Tool (`Win + Shift + S`)**, File Explorer copied images, web browsers, and screenshots.
- 🛡️ **Hardware Palm Rejection & Object Drag Lock**:
  - Screen lock during stylus handwriting to prevent accidental palm shifts.
  - 1,200ms grace protection window between strokes.
  - Contact geometry filtering rejecting accidental palm touches (>28px).
  - Object drag lock ensuring the screen never shifts while moving or resizing images and lasso selections.
  - Radiant glowing neon emerald shield button indicator with pulsing aura on the toolbar.
