## Run a portable ZIP

1. Download the Windows x64 ZIP for the version you want.
2. Extract **all** files into a separate folder for that version.
3. Open **BetterNotePC.exe** from the extracted folder. Do not run it from inside the ZIP.

These downloads are for Intel/AMD x64 PCs and Intel Surface devices, not native ARM64 builds. Back up your notebooks before switching versions. Use Backup / Restore when moving work between separate installations. Earlier versions do not include all later fixes.

## What's included in 1.3.0.0

- Illustrated offline guide with 10 categories and 55 lessons.
- Single-row toolbar, improved pen input and Whiteboard touch navigation.
- PDF and editable .bnote import/export improvements.
- Incremental backups, separate backup histories per device and manual Restore.
- Improved restore progress, folder handling and conflict-copy decisions.
- BetterNote icons, offline fonts and daily update checks.
